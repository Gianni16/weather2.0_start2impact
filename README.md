# Weather App ☀️🌧️

A simple front-end weather application built with HTML, CSS, JavaScript, and jQuery.  
It fetches real-time weather data using the OpenWeatherMap API based on city name input or current geolocation. 🌍📍

## Features ✨

- 🔍 Search weather by city name  
- 📍 Get current location weather using geolocation  
- 🌡️ Displays temperature, max/min temperature, humidity, wind speed, and weather icon  
- 🎨 Responsive and clean UI with simple animations and interactive elements  

## Technologies Used 🛠️

- HTML5  
- CSS3  
- JavaScript (ES6)  
- jQuery  
- OpenWeatherMap API  

## How to Use ▶️

1. Open `index.html` in your browser.  
2. Enter a city name and click **Search** to get the current weather.  
3. Alternatively, click the location pin icon 📌 to allow the browser to detect your current location and show the weather.
